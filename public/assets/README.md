# Art formats

Characters are extracted from the rip by `tools/extract_overworld.py`; mons and
tiles are generated by `tools/make_sprites.py`. See `ASSETS.md` at the repo
root for sources and licensing.

Nothing here is required. Every slot falls back to a colored rectangle, so you
can swap one file at a time and watch it appear. Missing files are listed in
the dev console on load.

## Characters — `characters/<name>.png`

`player` `professor` `greeter` `scale` `build` `warstory` `wacky` `hint` `leader`

Standard GBA overworld layout, **16x24 per frame**, 3 columns x 4 rows:

```
        col 0    col 1    col 2
row 0   down     down-A   down-B      <- facing the camera
row 1   up       up-A     up-B
row 2   left     left-A   left-B
row 3   right    right-A  right-B     <- optional, see below
```

Column 0 is the standing pose; columns 1 and 2 alternate while walking.
Sheet total: **48 x 96 px**. A standing-only NPC repeats its single frame
across all three columns.

Most rips omit row 3 and mirror the left row instead. That is the default
(`mirrorRight: true` in `src/content/assetManifest.ts`). If your sheet has a
real right-facing row, set it to `false` for that character.

The 24px height is intentional: a 16x16 body sits on the tile and the head
overhangs 8px above it, which is how Pokémon overworld sprites work.

## Mons — `mons/<id>.png`

`blobheart` `goose` `francis` `maytrix` `tesselation`

Single frame, **64x64**, transparent background (RGBA PNG).

Do not hand-place these: drop your drawing in `art-source/mons/` at any size
with a flat background and run `python3 tools/import_mon.py`, which handles
keying, fitting and bottom-alignment for you.

64x64 is the GBA's own battle-sprite size and this canvas is exactly a GBA
panel, so design at 1:1 — do not draw large and downscale, it will blur.

**Bottom-align the creature.** Sprites are placed feet-on-platform, so any
empty rows beneath the feet make it hover in-game. Fill the bottom row.

Fill as much of the 64x64 box as the creature naturally wants; a small
creature can leave space at the top and sides, just not underneath. The same
image is reused in the professor's starter line-up, scaled to 28px, so keep
the silhouette readable when it is small.

## Tiles — `tiles/gym.png`

One atlas, **16x16 cells**, at least 4 columns x 3 rows (64 x 48 px):

```
        col 0      col 1      col 2      col 3
row 0   wall       floor      carpet     platform
row 1   desk       plant      sign       bookshelf
row 2   gate       entrance   panel off  panel on
```

Cell coordinates live in `TILES` in `src/world/tilemap.ts` — rearrange the
atlas however you like and update the `atlas: { col, row }` values to match.

## Changing frame sizes

`frameW` / `frameH` per slot in `src/content/assetManifest.ts`. `TILE` is in
`src/engine/config.ts`; changing it only affects viewport math.
